# وشيجة — Washijah

منصة مدرسية واحدة تجمع كل شيء لطلاب الثانوي.

## الموجود حالياً
- **الصفحة الرئيسية** (`index.html`) بنفس الهوية البصرية (المرجاني، العنابي، الكريمي، خط IBM Plex Sans Arabic)، وتشتغل على الجوال والكمبيوتر وباتجاه من اليمين لليسار.
- **مؤقت التركيز** شغّال (نسخة أولية).
- الخانات الثانية تطلع رسالة «قريباً» لين نبنيها.

## الخانات (نفصّلها بعدين)
| المفتاح | الخانة |
|---|---|
| `plan` | خطتي المستقبلية (AI) |
| `ai` | المساعد الذكي: يحل الأسئلة ويصحح الإجابات |
| `schedule` | جدولي |
| `focus` | ركّز: مؤقت مذاكرة ومنافسة |
| `level` | مستواي |
| `resources` | المصادر اللي ينزّلها المعلمين |
| `community` | المجتمع: مشاركة محتوى وفيديوهات |
| `messages` | الرسائل |
| `feedback` | اقتراحات للمعلمين |
| `grades` | الدرجات |
| `rewards` | المحفزات |

التطبيق كله في ملف واحد `index.html` (التصميم والكود والشعار داخله)، والخانات معرّفة في مصفوفة `MODULES` داخل وسم `<script>`.

## التشغيل
افتح ملف `index.html` بأي متصفح (جوال أو كمبيوتر)، ما يحتاج تثبيت شيء.
