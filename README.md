# وشيجة — Washijah

منصة مدرسية واحدة تجمع كل شيء لطلاب الثانوي. نسخة تجريبية للعرض.

## وش فيها
- **الدخول**: تختار طالب / معلم / ولي أمر / إدارة، وتكتب اسمك بس. ما فيه بريد ولا كلمة مرور.
- **الطالب**:
  - الرئيسية، وخطتي المستقبلية (حلمه، تخصصه وجامعته من أي مكان بالعالم، نسبه، دوراته ومصادره، ووقته).
  - جدولي: جدول حر فيه مهامه بنفسه، اختبارات كتذكير، وتكرار أسبوعي. وجلسات الخطة لو بيغيرها يسأله ليش ومتى يعوضها.
  - دورات القدرات والتحصيلي (المفكر، المعاصر، المنصف، يلو، أ. إياد، أ. إيهاب…): يسأله وين وصل، ومتى اختباره، وكم يوم يذاكر، ويوزع أرقام الدروس على الأيام، ويخلي آخر أسبوعين للمراجعة.
  - المساعد الذكي: يحل ويصحح ويشرح، ويقبل صورة السؤال.
  - ركّز: مؤقت ما يتوقف، وأشجار، ومنافسة (فصلي / مدرستي).
  - المجتمع (الفصل / الصف / المدرسة)، والرسائل، والمصادر، والمستوى، والمحفزات، والاقتراحات.
- **المعلم**: واجبات واختبارات تطلع للطلاب، مصادر (روابط وملفات)، مستوى طلابه، اقتراحات الطلاب، ومساعد ذكي يضيف أشياء للتطبيق.
- **ولي الأمر**: مستوى ولده، ووش ناقص فيه، والمسابقات. خطة الطالب ما تظهر له لأنها خاصة.
- **الإدارة**: أخبار ومسابقات وإعلانات، جوائز المنافسة، وتقارير.

> عدد دروس الدورات **تقديري**، والطالب يعدّله. البيانات تنحفظ في المتصفح نفسه، فاللي يضيفه المعلم يطلع للطالب على نفس الجهاز.

## التشغيل
- افتح `index.html` بأي متصفح، أو انشره على Vercel (تحت).
- **الذكاء الاصطناعي**:
  - داخل Claude: يشتغل بحساب اللي فاتح الصفحة.
  - على Vercel: يشتغل عن طريق `api/ai.js` لما تضيف المفتاح.

## النشر على Vercel
1. ادخل vercel.com وسجّل بحساب GitHub، واضغط **Add New → Project** واختر هذا المستودع، وبعدها **Deploy**.
2. (للذكاء الاصطناعي) ادخل **Settings → Environment Variables**، وأضف `ANTHROPIC_API_KEY` = مفتاحك من console.anthropic.com، وبعدها **Redeploy**.
3. اختياري:
   - `AI_MODEL` عشان تغيّر النموذج (الافتراضي `claude-opus-5-5`، والأرخص `claude-haiku-5-5`).
   - `AI_LIMIT_PER_10_MIN` عشان تحدد كم طلب يقدر يسويه الجهاز الواحد كل ١٠ دقايق (الافتراضي ٣٠).

## للمطوّرين
الكود في `src/` (`index.html` و`styles.css` و`app.js` و`more.js`). بعد أي تعديل شغّل `python3 build.py` (أو `npm run bundle`)، وهو يبني `index.html` كملف واحد.
