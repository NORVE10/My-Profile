# وشيجة — Washijah

منصة مدرسية واحدة تجمع كل شيء لطلاب الثانوي.

## التشغيل
افتح ملف `index.html` بأي متصفح (جوال أو كمبيوتر)، ما يحتاج تثبيت شيء.

## الموجود حالياً
- **الرئيسية**: سؤال سريع للمساعد، مهام اليوم، الخانات، مؤقت «ركّز»، أخبار المدرسة.
- **المساعد الذكي**: يحل الأسئلة خطوة بخطوة، يصحح إجابة الطالب، يعطي تلميح، يشرح دروس، ويقبل صورة السؤال. ويعرف خطة الطالب وجدوله.
- **المنافسة**: لوحة ترتيب كاملة (فصلي / مدرستي) حسب دقائق التركيز، والطالب يطلع فيها كل ما كمّل جلسة.
- **خطتي المستقبلية**: الطالب يجاوب ٥ خطوات (حلمه وشغفه ومدى اهتمامه، التخصص والجامعة، النسب، البرامج والتدريبات، وقته الفاضي)، وتطلع له خطة بمراحل وتواريخ، والفرق بين نسبه الحالية والمطلوبة، ونصايح.
- **جدولي**: جدول أسبوعي بمهام محددة (أرقام ومصادر يختارها الطالب، مثل «خلّص ٦ دروس كمي في المفكر»)، والطالب يعلّم على اللي خلّصه، ويطلب من الذكاء الاصطناعي يعدّل الجدول أو يساعده في أي جلسة.
- **الجامعات**: جامعات السعودية وأشهر جامعات العالم كاقتراحات، والطالب يقدر يكتب أي جامعة.
- الذكاء الاصطناعي يكتب الخطة لما الصفحة مفتوحة داخل Claude. وبدونه يشتغل مولّد داخلي يسوي خطة مبدئية.
- البيانات تنحفظ في متصفح الطالب نفسه بس.

## للمطوّرين
الكود في مجلد `src/` (`index.html` و`styles.css` و`app.js` والصور).
بعد أي تعديل شغّل:
```
python3 build.py
```
وهو يبني `index.html` النهائي كملف واحد.
